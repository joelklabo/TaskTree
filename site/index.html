TTD loop

Test · Trace · Document

The repo bakes in TTD: failing test first, trace artifacts every run, docs updated alongside code. CI enforces the rhythm.

  1. 1

    Start with a failing test/trace

    Capture the repro in pytest, Vitest, or a flow trace. CI surfaces it in summaries.

  2. 2

    Fix with artifacts

    Run lint/test/e2e; upload coverage, Playwright videos, and debug bundles.

  3. 3

    Document immediately

    README blocks auto-refresh; PR templates nudge agents to link previews and traces.
